# Доски холста «Пастели» в репозитории

Копия экранов с холста «Daftar · учёт расходов» (ссылка — в [`docs/pastel/README.md`](../docs/pastel/README.md)),
чтобы агентам не нужен был доступ к приватному артефакту. Снято 2026-10-19 с версии холста
`1792405887-443d`. Если на холсте что-то поменялось — пересоберите (ниже).

Продукт с тех пор переименован в Kapelka (FT-168): на досках — прежнее имя, в коде — «Kapelka» и «kapelka» в шапке.
При сверке экрана это не расхождение. Доски и исходники здесь — копия холста как есть, их не правят руками.

## Что где

| Путь | Что |
|---|---|
| [`index.md`](index.md) | Название доски → картинка и исходник, по рядам холста. Искать по названию из поля `Design` задачи |
| `screens/<Имя>.png` | Доска как на холсте: телефон 390×844, показ 880×844, масштаб 1:1 |
| `prototype/<Имя>.dc.html` | Исходник доски с холста как есть |
| `tools/` | Скрипты, которыми всё это собрано |

**Картинки** отрисованы рантаймом самого холста в Chromium — это тот же экран, что на холсте, в начальном
состоянии (доски интерактивны; другие состояния — отдельные доски). Шрифт — Manrope из
`@fontsource-variable/manrope` webapp: доски просят ту же гарнитуру у Google Fonts.

**Исходники.** Варианты (тёмная тема, другое состояние) — короткие файлы: они подключают основную доску
через `<dc-import name="…">` с параметрами (`dark`, `filled`, `view`…). Разметка, тексты и логика состояний —
в основной доске. Формат: `<x-dc>` с разметкой, `{{…}}` — значения из `renderVals()` в `<script>` внизу.

## Как сверять экран

- Экран снимают в 390×844 и кладут рядом с `screens/<Имя>.png` в той же теме.
- **Цвета — из токенов** (`docs/pastel/tokens.json` → Tailwind-имена), не из hex в исходнике доски: в
  досках цвета зашиты. Токены в репозитории новее копии на холсте (v5 против v4); разница одна —
  `seg-off` в тёмной теме `#b0b0b8`, на холсте `#9d9da6`.
- Текст, отступы, размеры и поведение — из исходника доски.

## Что сюда не вошло

- Прежние версии «Пастели» (`*_v1…_v6`, ряд «История · прежние версии Пастели»), экраны Paper Terminal
  (`Main*`, `Add*`, `Voice*`, `Review*`) и вкладка «Сравнение стилей» — остались на холсте.
- «Цвет», «Типографика», «Telegram» из поля `Design` у FT-092 — разделы артефакта дизайн-системы, не холста;
  их содержание — в `docs/pastel/design-system.md` и `docs/pastel/tokens.json`.

## Как пересобрать

1. Скачать с холста все `project/Pastel_*.dc.html`, `project/canvas.json` и `artifact-type/dc-runtime.js`
   (в Claude Code — инструментом Artifact, `action: "read"` с `paths`). Рантайм в репозиторий не кладём:
   это код типа артефакта.
2. Сложить доски в одну папку, рантайм — туда же под именем `support.js` (доски подключают `./support.js`).
3. Отрисовать и собрать указатель:

   ```bash
   node design/tools/render-boards.js --site=<папка> --out=design/screens \
     --fonts=webapp/node_modules/@fontsource-variable/manrope <Имя> …   # без имён — все доски папки
   node design/tools/build-index.js --canvas=<canvas.json> --site=<папка> --list=<список имён> --out=design/index.md
   cp <папка>/Pastel_*.dc.html design/prototype/   # кроме *_v*
   ```

   Без скачанного браузера Playwright: `CHROMIUM_PATH=<путь к chromium>`. Сеть не нужна: запрос шрифта к
   Google Fonts скрипт отвечает локальным Manrope.
4. Проверить, что каждое название из полей `Design` находится в указателе (доской или рядом):
   `node design/tools/check-design-refs.js docs/pastel/tasks.md design/index.md` — в выводе `unresolved: 0`.
