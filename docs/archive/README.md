# Архив документации

Здесь лежат документы, которые больше не являются действующими правилами. Они сохранены ради истории решений — читать их как руководство нельзя.

Если факт нужен сейчас, ищи его в действующем документе или в коде. Если факт есть только здесь — он, скорее всего, устарел.

## Дизайн (перенесено 2026-08-13)

Четыре документа описывали дизайн одновременно, и один из них — помеченный в `CLAUDE.md` как обязательный — противоречил коду: предписывал шрифт Inter, когда в проекте уже стоял Onest. Из-за этого следование «официальным» правилам давало неверный результат.

Все четыре заменены одним: [`docs/knowledge-base/10-design-guidelines/design-system.md`](../knowledge-base/10-design-guidelines/design-system.md).

| Файл | Чем был | Почему в архиве |
|---|---|---|
| `design-guidelines.md` | 473 строки, помечен MUST FOLLOW | Устарел: Inter, импорт Inter с Google Fonts, «вес 500» в антипаттернах. Полезные величины (тач-таргеты, длительности анимаций, шкала радиусов) давно живут токенами в `globals.css` |
| `style-direction.md` | Тезис о нейтральном интерфейсе, роли цвета, иерархия действий | Содержание верное, целиком перенесено в новый документ |
| `DESIGN_SYSTEM_SUMMARY.md` | Сводка примитивов и решений | Содержание верное, дублировало два других документа |
| `design-system-guide.md` | Был `08-development/design-system.md` | Содержание верное, стало основой нового документа |
