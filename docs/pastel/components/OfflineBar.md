# OfflineBar

Как главная показывает, что связи нет.

- **Строка под шапкой** — карточка `card`, `radius-card`, высота от 48px, `role="status"`: иконка «нет сети» 20px и одна фраза 14px/700 «Нет связи — записи сохранятся и отправятся сами». Других пояснений здесь нет: про голос и чек говорят их собственные экраны.
- **Метка у записи.** Подпись строки начинается со слов «Ждёт связи», перед ними иконка часов 13px: «Ждёт связи · Кофе». Метка идёт первой, чтобы её не обрезало многоточие. Сумма и цвет не меняются.
  - В коде (ревью FT-129) «проверьте сумму» идёт сразу за меткой, тоже до заметки: «Ждёт связи · проверьте сумму · Обед». Даже одна «Ждёт связи · проверьте сумму» на 390px шире строки (189 из 187px), поэтому подпись такой записи может занять две строки (строка растёт, часы — у первой); остальные подписи — в одну строку с многоточием. «Без заметки» у ждущей записи не пишется: «Ждёт связи» без продолжения. Записи одной фразы стоят в её порядке.
- **Что работает без связи:** кнопки трат, ручной ввод, простой текст («такси 18к, кофе 25к» — две записи; «55$» — на долларовый счёт; «45» без «к» — 45 000 с пометкой «проверьте сумму»). Toast: «Записано на этом устройстве · Такси · −18 000 сум · отправится со связью».
- **Что не работает:** голос и чек. Кнопка микрофона без связи — `track` вместо `primary`, нажатие ведёт на ProblemScreen с выходом «Ввести вручную».
- **В коде (FT-129):** строка — `OfflineBar` (`shared/ui/pastel`), метка — `RecordDayList` по `pending` записи из очереди
  (`entities/transaction`, `usePendingRecords`). «Нет связи» — событие браузера `offline`, запись без ответа сервера или
  «Записывать без связи» под медленной загрузкой; ответ сервера возвращает связь (`shared/lib/offline`) — страница
  шлюза с `502`/`503`/`504` не ответ сервера. «Отменить» во время отправки скрывает запись сразу; на устройстве она
  помечена `cancelled`, пока сервер её не удалит.
