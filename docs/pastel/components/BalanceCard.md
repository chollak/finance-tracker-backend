# BalanceCard

Карточка баланса — главный акцент экрана: сумма по всем счетам, раскрываемый список счетов и одна строка-вывод.

- Фон `primary`, текст `on-primary`, подписи `on-primary-muted`, `radius-hero`, отступы `space-5`.
- Сумма — стиль `balance`, единица рядом 18px, 600, `on-primary-muted`. Валюту отображения переключает Segmented в шапке.
- Кнопка «3 счёта» с шевроном раскрывает счета внутри карточки (`aria-expanded`). Каждая строка: название слева, остаток справа в своей валюте.
- Строка-вывод: полоса 8px (`hero-track`, заполнение `hero-fill`) и одно предложение с выделенной цифрой: «В октябре потрачено 47% дохода».
- В тёмной теме карточка светлая: инверсия из токенов, отдельной вёрстки не нужно.
