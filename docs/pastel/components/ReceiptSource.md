# ReceiptSource

Откуда взяты данные чека и что с ними не так. Всегда одна строка под суммой и, если нужно, одна плашка над карточкой суммы.

- **Источник** 13px/700 `muted` с кружком 18px:
  - «✓» на `pastel-mint` с `mint-ink` — «Из QR-кода — суммы точные»;
  - «!» на `pastel-butter` с `pastel-ink` — «Распознано по фото — сверьте итог и отмеченное»;
  - из бота — «Чек 20:05 из бота · по QR-коду».
- **Неуверенная категория** — чип с пунктиром 2px `muted`, без пастели, со знаком «?». В выборе категории плитка тоже пунктирная.
- **Неразобранная строка** — курсив «Строка не разобрана», под ней «сумма — по разнице с итогом», сумма со знаком «?». Строка сверки под итогом: «Разобрал 8 строк из 9: 245 800 из 254 300 сум. Итог взят с чека.».
- **Плашка «Похоже, эта покупка уже записана»** — фон `track`, без обводки, внутри строка записи. Ниже текстовая кнопка «Нет, это другая покупка». Главная кнопка экрана — «Дополнить запись».
- **Плашка «Итог не попал в кадр»** заменяет карточку суммы. В ней сказано, сколько позиций видно и на какую сумму. Главная кнопка — «Переснять», ниже «Ввести вручную».
