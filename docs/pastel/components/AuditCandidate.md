# AuditCandidate

Карточка одной траты в ревизии. Человек решает «Нужно» или «Лишнее».

- Карточка `card`, `radius-card`, отступ 16px, промежутки 10px. Атрибут `aria-label` пересказывает вид, заголовок, сумму и отметку.
- Первая строка: кружок категории 24px (пастель, буква `pastel-ink`) и «Часто и понемногу · Кафе» 13px/700 `muted`.
- Заголовок 17px/800 и сумма 15px/800 справа. При переносе сумма прижимается вправо: `margin-left: auto`. У подписки сумма идёт с «в месяц».
- Причина 13px/600 `muted`, только утверждение с числами. Дальше текстовая кнопка «Показать 13 операций» с `aria-expanded`. Список — максимум 5 строк, затем «Показать все 13».
- Выбор — Segmented на всю ширину: «Нужно / Лишнее», `aria-pressed`. Повторное нажатие снимает отметку.
- После отметки причина и операции скрываются. Для лишнего повторяющегося появляются «Что делаем дальше» и второй Segmented «Вдвое меньше / Отказаться», под ними строка 13px/700 «Лимит 224 000 сум в месяц · экономия 224 000 сум». Подписка получает только строку «Отменить подписку · экономия 50 000 сум в месяц». Разовая покупка получает пояснение `muted` без цели.
