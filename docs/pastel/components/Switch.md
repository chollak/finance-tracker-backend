# Switch

Переключатель «включено / выключено» внутри шторки настроек.

- **Строка** — вся кнопка 60px, `role="switch"`, `aria-checked`: подпись-действие слева («Присылать сводку», «Предупреждать»), переключатель 52×32 справа.
- **Включено** — дорожка `primary`, ручка 24px `on-primary` справа.
- **Выключено** — прозрачная дорожка с контуром 2px `muted`, ручка 18px `muted` слева. Контур виден на `sheet-card` в обеих темах; светло-серая дорожка с белой ручкой не годится — её почти не видно.
- Под переключателем, только когда он включён, — выбор времени: 4 таблетки 44px в `radiogroup` («20:00 21:00 22:00 23:00»), выбранная — `primary`.
- Изменение применяется сразу; кнопка «Готово» внизу шторки просто закрывает её.
