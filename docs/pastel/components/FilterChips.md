# FilterChips

Фильтры истории — строка чипов под поиском, листается вбок.

- Первый чип — «Категория ▾»: открывает Picker с группами и плиткой «Все категории». Когда категория выбрана, чип показывает её точку и название.
- Дальше чипы счетов: «Наличные», «Карта», «Доллары». Нажатие включает, повторное — снимает. Одновременно один счёт.
- Чип 44px, 14px/700, таблетка. Выключенный — `card` с `ink`, включённый — `primary` с `on-primary`, `aria-pressed`.
- Когда есть запрос или фильтр, под чипами строка результата `label`: «2 операции · −109 000 сум» и текстовая кнопка «Сбросить». Если ничего не нашлось, строки нет — говорит EmptyState.
- Запись, которую только что исправили, остаётся в списке, пока фильтр не поменяют.
