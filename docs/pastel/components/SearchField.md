# SearchField

Поле поиска в истории операций. Ищет по категории, заметке, счёту и сумме.

- Таблетка 52px на `card`, слева лупа 20px `muted`, поле `body` 15px/600. Подсказка: «Такси, кафе, 25 000…».
- Когда в поле есть текст, справа круглая кнопка «Очистить поиск» 44px на `track`.
- Все слова запроса должны найтись. Цифры сравниваются с началом суммы: «25 000» найдёт кофе за 25 000, но не зарплату 12 500 000.
- Результат обновляется на каждый символ, без кнопки «Найти». У поля невидимая подпись «Поиск по операциям», клавиша клавиатуры — «Поиск».
