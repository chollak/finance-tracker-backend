# CategoryBars

Категории за период — главный «график» аналитики: отсортированные полосы одного цвета.

- Заголовок «По категориям» (`section`), справа легенда засечки 13px `muted`: «▏ было за 1–14 сентября» (для скринридера скрыта — сравнение есть в описании каждой строки).
- Карточка `card`, строки 60px — кнопки, открывают категорию. Кружок 40px с пастелью категории и буквой, название `body-strong`, справа сумма 15px/800 без знака.
- Под названием полоса 6px на `track`, заливка `ink`, длина — доля от наибольшего значения обоих периодов. Засечка прошлого периода 2×12px `muted` с кольцом 2px `card`.
- Справа от полосы — изменение 13px/700 `ink`: «↑ 40%», «↓ 15%», «как было», «новое»; у незаконченного месяца доходов — «пока нет», «пока 60%» цветом `muted`. Если сравнивать не с чем — доля «28%» `muted`. Колонка не уже 72px.
- Сортировка по сумме за период; категории только из прошлого периода — в конце. Описание строки: «Кафе: 1 092 000 сум, 14% расходов, на 40% больше, чем за 1–14 сентября».
