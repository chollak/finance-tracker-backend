# CategoryTile

Выбор категории на экране ввода: сетка 4×2 пастельных плиток с названиями.

- Плитка 48px высотой, `radius-tile`, фон — пастель категории (таблица в README системы), текст `pastel-ink` 13px/700.
- Выбранная плитка — внешнее кольцо: 2px цвета фона под плиткой, затем 2px `ink` (в шторке — `sheet`, роль `radio`, `aria-checked`). Цвет фона не меняется: выбор видно по кольцу, а не по оттенку. Старая внутренняя обводка `pastel-ink` в тёмной теме сливалась с фоном и больше не используется (экран ввода переведён на кольцо).
- Предположение ИИ — пунктирная обводка 2px `ink` с отступом 2px.
- Наборы расходов и доходов разные, по 8 категорий; цвета закреплены за категориями и совпадают с графиками.
- В списках та же категория — кружок 40px того же цвета с первой буквой (см. TransactionList).
