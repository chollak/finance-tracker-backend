# ProblemScreen

Один шаблон для всего, что пошло не так: нет связи для голоса или чека, нет доступа к микрофону, ничего не расслышал, вход не подтверждён.

- **Сверху вниз:** «Отмена» или логотип в шапке; кружок 56–64px на `track` с линейной иконкой ситуации (перечёркнутый микрофон, перечёркнутая камера, «нет сети», часы); заголовок 26–28px/800; один абзац 16px `muted`. В нём сказано, что случилось и что делать. Ниже, если нужно, шаги в карточке `card` с номерами в кружках 28px.
- **Заголовок называет ситуацию человеческими словами** и без слова «ошибка»: «Ничего не расслышал», «Голос работает только со связью», «Вход не подтвердили». Коды и технические причины не показываем.
- **Внизу одна главная кнопка — выход, который точно сработает:** «Написать текстом», «Ввести вручную», «Войти через Telegram». Если есть второй разумный путь, он идёт текстовой ссылкой 44px под кнопкой: «Доступ включён — попробовать снова».
- **Тексты под место.** Для браузера свои шаги («Нажмите значок слева от адреса сайта»), для Telegram свои («Откройте настройки телефона»). Без связи пишем «на этом устройстве», а не «на телефоне».
- Анимация (пульс в ожидании входа) отключается при `prefers-reduced-motion` — иконка остаётся понятной и без неё.
