# SummaryTiles

Две плитки под карточкой баланса: доход и расход за текущий месяц.

- Сетка в две колонки, промежуток `space-3`.
- Доход: фон `pastel-mint`, текст `mint-ink`. Расход: фон `pastel-peach`, текст `peach-ink`. Одинаково в обеих темах.
- Подпись 13px, 700 («Доход за октябрь»), сумма — стиль `tile-value` со знаком.
- `radius-card`, отступ `space-4`. Сумма не переносится: при длинной валюте уменьшайте шрифт, а не обрезайте.
