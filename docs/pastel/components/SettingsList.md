# SettingsList

Разделы экрана «Ещё». Карточка `card`, `radius-card`; над ней заголовок раздела 13px/700 `muted`, под ней при необходимости одна поясняющая строка 13px `muted`.

- **Строка** — 64px: кружок 40px на `track` с линейной иконкой, название 15px/700, под ним текущее состояние 13px `muted` («Каждый вечер в 21:00», «Выключено», «Как в Telegram»), справа шеврон. Строки разделены линией `line`.
- **Три вида строк.** Ссылка на раздел (шеврон). Кнопка, открывающая шторку (шеврон, `aria-haspopup="dialog"`). Действие на месте — без шеврона («Скачать все записи», «Выйти»). Статичная строка (имя аккаунта) не похожа на кнопку: иконка в контуре, без заливки.
- **Сохранять нечего.** Изменение применяется сразу и видно в подписи строки. Повторное действие, которое уже выполнено, блокируется до конца Toast («Отправлено — файл уже в чате с ботом»).
- **Подписи состояний** короткие и конкретные, с временем и числами; «Выключено» — без извинений.
- В браузере добавляется раздел «Аккаунт»: имя и «Выйти · Только в этом браузере · записи останутся».
