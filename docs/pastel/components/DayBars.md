# DayBars

Траты категории по дням периода. Отвечает «когда», а список ниже — «на что».

- Карточка `card`, заголовок «По дням» 15px/800. Область 112px — одна кнопка: касание выбирает ближайший день, повторное снимает выбор; Enter выбирает самый крупный день.
- Столбцы `ink`: 14px шириной до 16 дней в периоде, 6px — для целого месяца; скругление 4px сверху (3px у узких), минимум 3px высоты у ненулевого дня. Ось — линия 1px `line`.
- Подписи оси стилем `axis`: 1, каждый 7-й день, последний. Выбранный день — подложка `track` на всю высоту, подпись `ink`/800, соседние подписи (±2 дня) скрыты, остальные столбцы — `chart-dim`.
- Под графиком кнопки ‹ › 44px на `track` и строка `aria-live`: без выбора — «Коснитесь столбца или выберите день стрелками» `muted`; с выбором — дата 13px/600 `muted` и «318 000 сум · 1 операция» 15px/800 `ink`. Кнопки на краях — `aria-disabled`, фокус не теряется.
- Выбранный день фильтрует список операций; в шапке списка чип «5 октября ✕» (`primary`, 44px).
- Если в категории меньше 2 операций — графика нет.
