# AnalyticsHero

Сводка вверху аналитики: сколько, по сравнению с чем, и один вывод.

- Карточка `primary`, `radius-hero`, отступы 16px 20px 20px. Подпись периода 14px/600 `on-primary-muted`: «Расходы · 1–14 октября».
- Сумма стилем `balance` (46px), длиннее 11 знаков — `balance-sm` (38px). «сум» 18px `on-primary-muted`. Если внутри пересчитанные доллары — знак «≈».
- Строка сравнения 13px/600 `on-primary-muted`: «↑ 10% к 1–14 сентября · на 714 400 сум больше». Для доходов незаконченного месяца — «За весь сентябрь — 15 210 000 сум». Первый месяц — «Первый месяц учёта — сравнивать пока не с чем».
- Под линией `hero-track` — единственная строка-вывод 15px/700 `on-primary`. Правила выбора — в разделе «Аналитика» README.
- Первые 7 дней строки сравнения нет, вывод: «Пока записи за 3 дня — выводы через 4 дня, сравнение в ноябре».
