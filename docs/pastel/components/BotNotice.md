# BotNotice

Сообщения, которые бот присылает сам. Они должны быть редкими и полезными.

- **Итоги дня, 21:00.** Жирный заголовок «Итоги дня · 14 октября», затем «Потрачено 210 400 сум · 2 записи». Через пустую строку — до 3 категорий («Продукты · 186 400»). Ещё через пустую строку — одна строка-вывод о месяце. Кнопка «Открыть Kapelka ↗».
- **День без записей.** «Записей нет. Трат правда не было?» с кнопкой «Да, не было». Приходит не больше 2 вечеров подряд и снова — после первой записи.
- **Цель.** «Цель «Такси»: 84 000 из 102 000 сум», остаток лимита и курсивом, когда бот напишет снова. Приходит один раз на 80% лимита и один раз на превышение.
- **Подписка.** Дата списания абсолютная: «3 ноября Кинопоиск спишет 50 000 сум». Кнопки «Отменено | Оставить».
- **Ревизия готова.** «5 трат на проверку — пара минут», ссылка «Открыть ревизию ↗» и «Позже». «Позже» повторяется только один раз.
