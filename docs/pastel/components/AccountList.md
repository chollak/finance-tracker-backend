# AccountList

Список счетов на экране «Счета» — карточка `card`, `radius-card`, заголовок раздела «Счета» 13px/700 `muted`.

- **Строка счёта** — кнопка 64px во всю ширину: кружок 40px на `track` с иконкой типа (наличные — купюра, карта — карточка, доллары — знак «$»), название 15px/700, под ним «сумы · карта» 13px `muted`, справа остаток 15px/800 с валютой. Строки разделены линией `line`.
- **Долларовый счёт** показывает под остатком «≈ 5 313 000 сум» 13px `muted` — по действующему курсу. Так итог над списком можно сверить глазами.
- **«Добавить счёт»** — последняя строка: пунктирный кружок 40px с плюсом и подпись 15px/800. Открывает шторку «Новый счёт».
- **«Скрытые счета · N»** с шевроном появляется под списком, только если что-то скрыто. Открывает шторку со строками «Название / остаток» и кнопкой «Показать».
- У каждой строки `aria-label` с суммой: «Доллары, 420,00 USD, примерно 5 313 000 сум. Открыть счёт».
- Цвет пастели здесь не используется: у счетов нет своих цветов, пастель остаётся за категориями.
