# Skeleton

Загрузка главной при открытии mini app.

- **Та же раскладка, что у главной:** настоящая шапка с логотипом, карточка баланса цвета `primary` с полосами чуть светлее неё (в тёмной теме — чуть темнее), две плитки `track`, заголовок и карточка списка с кружками и полосами, ряд быстрых кнопок и поле ввода. Когда данные приходят, ничего не прыгает.
- **Пульс** — прозрачность 1 → 0,55, 1,6 с; при `prefers-reduced-motion` выключен. Контейнер `aria-busy="true"`, для скринридера — «Загружаю ваши счета и записи».
- **Спиннер посередине не используем.**
- **Через 6 секунд** под скелетом: «Дольше обычного — похоже, слабая связь. Записи не пропадут: они хранятся на сервере». Ниже главная кнопка «Попробовать снова» во всю ширину и текстовая ссылка «Записывать без связи», которая ведёт на главную в режиме без связи (OfflineBar). Скелет списка в этот момент короче, чтобы всё поместилось.
