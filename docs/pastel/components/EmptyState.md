# EmptyState

Пустой результат: ничего не нашлось по запросу или фильтру, или операций ещё нет.

- По центру круг 72px на `track` с иконкой `ink`, заголовок `section`, текст 14px/500 `muted`, ширина текста до 290px.
- **Ничего не нашлось** — текст называет, что искали: «Ничего нет по запросу «такси», на счёте «Доллары». Попробуйте другое слово или снимите фильтр.» Кнопка «Сбросить поиск и фильтры» — главная, 48px.
- **Пока нет операций** — без кнопки сброса, текст ведёт к вводу: «Запишите первую трату на главной — она появится здесь.»
- **Пустой месяц в аналитике** — иконка столбцов: «В октябре пока нет расходов», кнопка «Записать трату» ведёт на ручной ввод; для прошлого месяца — «В августе расходов не было», без кнопки.
- Роль `status`. Пастель здесь не используется: она только для категорий и денег.
