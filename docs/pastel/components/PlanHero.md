# PlanHero

Итог ревизии. Крупно показывает, сколько сэкономит план, ниже — как идут дела с начала месяца.

- Основа та же, что у AnalyticsHero: `primary`, `radius-hero`, подпись «Итог · отмечено 6 из 6» 14px/600 `on-primary-muted`. Подпись — `h2` с `tabindex="-1"`: после «Готово» на неё переходит фокус.
- Сумма стилем `balance`, без знака минус: экономия — не расход. Рядом «сум в месяц».
- Строка 13px/600 `on-primary-muted`: «Столько сэкономите, если держаться целей. В сентябре на лишнее ушло 1 504 000 сум». Для «вдвое меньше» в «лишнее» входит только часть сверх лимита.
- Под линией `hero-track` одна общая строка-тренд 15px/700 по всем целям: «По этим тратам с 1 октября — 365 400 сум, за те же дни сентября — 774 000 сум: уже на 53% меньше». Если стало больше — «пока на 12% больше».
- Без плана вместо суммы заголовок 24px/800 и пояснение: «Лишнего не нашлось», «Пока лишнего нет» (часть не разобрана), «Цели не нужны» (лишнее только разовое).
