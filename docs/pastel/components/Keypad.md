# Keypad

Цифровая клавиатура экрана ручного ввода: 3×4 клавиши-таблетки, без системной клавиатуры телефона.

- Клавиши `card`, `radius-pill`, высота `size-key`, промежуток `space-2`, цифры 23px/600 табличные.
- Нижний ряд: «000» (для сумм), 0, стереть. Для долларового счёта «000» становится запятой, после запятой — не больше двух цифр.
- Под клавиатурой — главная кнопка Button: «Сохранить расход» или подсказка, чего не хватает.
- Своя клавиатура не сдвигает экран и не перекрывает поля — в WebView Telegram системная клавиатура ведёт себя непредсказуемо.
