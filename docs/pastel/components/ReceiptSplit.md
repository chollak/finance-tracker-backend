# ReceiptSplit

Разделение чека по категориям.

- **Переключатель** «Разделить по категориям» во всю ширину строки, `role="switch"`. Дорожка 44×26, включённый — `ink`. Над ним подсказка ИИ, если он видит другие категории: «Порошок и губки похожи на «Дом» — можно разделить.».
- **Сводка** сразу под переключателем, жирным, в live-region: «Будет 2 расхода: Продукты 210 800, Дом 43 500.». При делении записи из бота добавляется «— вместо одной записи на 254 300».
- **Группы.** Заголовок группы — кружок категории 28px, название и сумма 15px/800. Позиции идут под ним с отступом. Каждая строка — кнопка 44px с шевроном: нажатие открывает выбор категории (Picker с контекстом «Шоколад · 11 000 сум»).
- **Кнопка сохранения** называет число записей: «Сохранить 2 расхода», «Разделить на 2 записи». Если все позиции оказались в одной категории — «Сохранить расход» (у записи из бота — «Оставить как есть»).
- Смена категории всего чека переносит только позиции с прежней основной категорией. Перенесённые вручную остаются, где были.
