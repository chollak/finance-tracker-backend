# MonthStepper

Листание месяцев в аналитике.

- Две круглые кнопки 44px на `card` по краям, между ними название месяца 16px/800 «Октябрь 2026» с `aria-live`.
- На границах кнопка `disabled` с прозрачностью 0.35: назад — не раньше первого месяца учёта, вперёд — не дальше текущего.
- Если месяц один (первые дни учёта), блок скрыт целиком.
- Смена месяца закрывает выбранную категорию и день.
