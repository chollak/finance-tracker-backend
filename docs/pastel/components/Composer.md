# Composer

Быстрый ввод внизу главной: частые операции в одно касание, поле для текста и кнопка голоса.

- Закреплён внизу экрана на фоне `bg`, отступ снизу `space-6`.
- **Частые операции** — горизонтальная лента чипов-таблеток высотой 44px, фон — пастель категории, текст `pastel-ink`: название 14px/700 и сумма 500. Касание сразу записывает операцию и показывает Toast с «Отменить».
- **Поле** — `card`, `radius-pill`, высота `size-button`, подсказка-пример «Кофе 25к, такси 18к…». Справа внутри — вторичная круглая кнопка ручного ввода (клавиатура).
- **Круглая кнопка** справа от поля — `primary` 56px: микрофон, пока поле пустое, стрелка отправки, когда есть текст.
- Отправленный текст или речь уходят на распознавание, затем — экран проверки записей.
- **Пока фраза распознаётся** (FT-146; на досках этого состояния нет, сделано по правилам системы):
  - в поле справа вместо камеры и клавиатуры стоит «Распознаю…» (`type-label`, `ink-muted`), как в строке «Распознаю» на доске «Голосовой ввод». Это `role="status"` с `aria-live="polite"`: область есть с самого начала и пустая, поэтому скринридер объявляет смену текста. Поле не меняет размер;
  - фраза остаётся в поле цветом `ink` и только для чтения. Длинная фраза кончается многоточием, перед «Распознаю…» есть зазор;
  - круглая кнопка остаётся `primary` — она занята, а не «чего-то не хватает». Вместо стрелки три точки по очереди мигают (`waiting-pulse`, при `prefers-reduced-motion` неподвижны). Для скринридера подпись кнопки — «Распознаю…».
- **Ответа нет 45 с** — это дольше худшего случая сервера: две попытки ИИ по 20 с. Тогда появляется Toast «Не дождался ответа / Текст остался в поле — отправьте ещё раз». Фраза остаётся в поле, фокус возвращается в поле. «Последние операции» перечитываются, потому что сервер мог всё же записать. Повторная отправка той же фразы идёт с тем же `clientId` и не задваивает записи.
