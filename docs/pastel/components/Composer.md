# Composer

Быстрый ввод внизу главной: частые операции в одно касание, поле для текста и кнопка голоса.

- Закреплён внизу экрана на фоне `bg`, отступ снизу `space-6`.
- **Частые операции** — горизонтальная лента чипов-таблеток высотой 44px, фон — пастель категории, текст `pastel-ink`: название 14px/700 и сумма 500. Касание сразу записывает операцию и показывает Toast с «Отменить».
- **Поле** — `card`, `radius-pill`, высота `size-button`, подсказка-пример «Кофе 25к, такси 18к…». Справа внутри — вторичная круглая кнопка ручного ввода (клавиатура).
- **Круглая кнопка** справа от поля — `primary` 56px: микрофон, пока поле пустое, стрелка отправки, когда есть текст.
- Отправленный текст или речь уходят на распознавание, затем — экран проверки записей.
