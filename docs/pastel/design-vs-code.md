# Дизайн «Пастель» против кода: экран за экраном

Источник дизайна — холст (ряды блоков и «Daftar · Пастель — текущие экраны») и дизайн-система «Пастель»
(см. [README](README.md)). Номера задач — из [`tasks.md`](tasks.md).

Легенда: **есть** — код можно взять почти как есть; **меняется** — логика или API есть, интерфейс новый;
**новое** — ни логики, ни интерфейса нет; **убираем** — в дизайне этого нет.

| Что | Предложение |
|---|---|

| Долги (`/debts`, разбор долгов из текста) | Убрать из интерфейса; разбор долгов выключить: «долг», «кредит», «рассрочка» → расход «Другое», как в прототипе бота (Д2, FT-099) |
